## Rule against unrequested results and repository references

At the user's request, the schema (`CLAUDE.md`) gained rule 0 under Operations: the author's experimental results and code-repository references are ingested only when the user explicitly asks for the specific item. The rule binds delegated agents, workflows and scheduled tasks, and it does not affect third-party papers' reported results or their published code links. The `sources/runs/` entry of the directory layout and the ingest trigger now point to the rule, and the user's global instructions carry the same restriction.
