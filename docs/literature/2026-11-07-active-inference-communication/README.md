## Provenance and reading scope

[Download records](downloads.md) and the [machine-readable provenance](provenance.json) record the versions, source URLs, retrieval results, page counts, and file identifiers. Reused PDFs include older arXiv versions of papers later published in journals or proceedings; a bibliographic publication year does not imply that the local file is the publisher version.

The new source notes summarize targeted readings of the primary methods and results. The collection does not claim a page-by-page review of every paper. Downloaded PDFs, extracted text, preview images, and the full `download_manifest.json` remain local under the vault publication policy. The published `provenance.json` retains bibliographic metadata and acquisition checks without source abstracts. The `reading/` extracts contain the first two pages for identity checks, and the `previews/` sheets show each first page. PDF checks establish document identity and readability; they do not certify the papers’ theoretical claims.

The Gwon PDF opens in both readers and renders, but pypdf reports nonfatal object-offset warnings. These are recorded in the manifest; the downloaded file was preserved unchanged.

## Scope of the synthesis

The wiki separates current message interpretation, future communication-policy evaluation, channel learning, and collective-boundary formation. It also separates possible roles supplied in a generative model, spectral graph partitions, and conditional-independence blankets. The synthesis explicitly qualifies the earlier flock-note claim about testing conditional dependence, using Appendix A.4 of the version 2 primary paper.

All 20 papers have local PDFs. There are no unresolved download gaps in this collection. The [validation record](validation.md) reports PDF and navigation checks, including the pre-existing README naming collision.
