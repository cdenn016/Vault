- **What contradicts it.** The newer `sources/manuscripts/dennis-2026-attention-unified.md:24` says: "it is nonflat unless that exponential is identity. There is no defined extremal ordering that makes it \"maximally curved.\""
- **Fix.** On all three pages, replace the wording with "non-flat unless $e^X=I$; the holonomy has the same conjugacy class on every triangle". Add a `> [!warning] Contradiction` callout on [[Lattice gauge theory]] citing both sources, and add a log line.

### C2. Is flatness of the regression links equivalent to the Markov property? (low)
- `wiki/concepts/Lattice gauge theory.md:176`: "the converse for the full Markov property is not claimed". This follows `dennis-2026-link-curvature.md:53`, which says "vanishing partial covariance for every single-intermediate triple is weaker than the full Markov property".
- `dennis-2026-attention-unified.md:24` says the opposite: "For a jointly Gaussian ordered sequence, the all-strict-triples regression cocycle is equivalent to the first-order Markov property."
- **Fix.** Add a contradiction callout on [[Lattice gauge theory]] that records both statements.
- > Editorial: the newer equivalence looks right. Taking $j=i-1$ for every $k<i-1$ makes the conditional cross-covariance of $\xi_i$ with the whole past, given $\xi_{i-1}$, equal to zero. For Gaussians that is joint conditional independence. Still, record both statements rather than resolving it silently.

### C3. Curvature certificate: eigenvalue invariants or Frobenius defect? (medium; the MAgent half is uncertain)
- `wiki/concepts/Non-flat connection and the photon analogy.md:37`: "the curvature certificate must be a conjugation-invariant of the loop (its eigenvalue spectrum, or $\operatorname{Re}\operatorname{tr}$), not the frame-dependent $\lVert W - I\rVert_F$."
- **Conflict on the same page.** Line 26, and also `wiki/concepts/Holonomy.md:22`, follow `dennis-2026-dynamic-links.md:24–26`:
  - every continuous class function on non-compact GL(K) "takes the same value at every unipotent element as at the identity";
  - the Frobenius defect of the reference-coordinate holonomy "vanishes only at $W=I$" and "is invariant under the passive gauge action because the generators are reference data".
- **MAgent item, uncertain.** Line 59, item (2), calls MAgent's $\lVert V_{ij}V_{jk}V_{ki}-I\rVert_F$ "frame-dependent … the same class of bug as `vfe3`". But line 51 declares $V_{ij}$ to be trivial-representation reference data, which is exactly the case where the Oct 3 note shows the defect is invariant under passive gauge changes. It is unclear whether line 59 means invariance under the link-moving reparameterization instead; there the defect is invariant only for orthogonal $h$.
- **Fix.**
  - Rewrite line 37: eigenvalue and Re tr certificates are necessary, but on non-compact GL(K) they cannot see unipotent holonomy. For frame-dressed links, the reference-coordinate Frobenius defect is invariant under passive gauge changes.
  - Re-qualify line 59 (2) to match.
  - Cite [[dennis-2026-dynamic-links]] in both places.
