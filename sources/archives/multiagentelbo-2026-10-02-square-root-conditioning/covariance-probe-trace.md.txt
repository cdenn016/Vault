# Probe and runtime trace for the mismatching covariance replay

October 2, 2026. Read-only trace against the original source.zip and the first executed diagnostic source.zip, with current scientific modules unchanged. This examines whether omitted probes alter the saved-path candidate recurrence; it does not diagnose the numerical Cholesky failure.

The original _run_grid reads a saved uniform, applies deterministic inverse categorical CDF and calls source_budget_probe. That function constructs mean/covariance/label tensors with torch.cat before source updates. Native row evaluation and comparison maps allocate their outputs. In _source_step, point displacements act on an explicit clone, selected covariance/cross blocks use advanced indexing, and solves and mean/covariance updates create new tensors. The zero-coordinate branch returns clones. Probe log-self and self-cost assignments mutate only probe-owned new tensors. Returned prefix_labels alias their argument, but no callee writes them and the runner clones every stored result. There is no input mutation path into live X, mean, covariance or assignments.

All six private random generators finish constructing the path tape before either grid begins. The probe CDF and all its callees consume no RNG, so omitting probes does not change later native draws. This establishes source-level recurrence equivalence under exact arithmetic, not bitwise replay equivalence under floating-point execution.

Original and diagnostic bootstraps set MKL_THREADING_LAYER=SEQUENTIAL and OMP_NUM_THREADS=MKL_NUM_THREADS=1 before importing Torch, use isolated C:/anaconda/python.exe, and call torch.set_num_threads(1). Both run CPU float64 in no_grad. Archived metadata identifies the same Torch 2.10.0.dev20251210+cu128 build. The original study ran four spawned workers; the diagnostics ran in their main process with additional reads. This changes allocation and operation history. No concrete changed arithmetic setting was found; absent recordings of affinity, floating-point flags and conditional reproducibility do not establish that any differed. The profile source discrepancy is line-ending normalization only.
