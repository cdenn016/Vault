# Deterministic source-adapted Gaussian replay

This phase follows the saved particle loss decomposition and the construction in `source-adapted-filter-construction.md`. It holds the native switching law, activation, externally supplied structural schedule, and retained observations fixed. The new candidate carries a full Gaussian conditional mean and covariance on the observed block-mean fiber. Source labels are predicted in ascending receiver order with shared positive spherical cubature and Gaussian regression after each label. Frozen-assignment propagation retains receiver and sender forces and every propagated covariance term. Conditioning uses the full covariance of the next observed block means.

The economical unchanged-assignment convention is declared before execution: an unchanged complete assignment uses the hold Gaussian for configuration prediction and subsequent conditioning, while its source probability includes both the global hold and same-assignment refresh. Changed assignments use the source-adapted Gaussian. This is an approximation to the two-branch reference, with normalized predictive rows. It does not claim an exact native posterior.

The old-matching-prefix shortcut has mass threshold 1e-12. At the first matching prefix below that probability, freeze the current Gaussian and score the remaining labels with normalized point-source rows at its mean. A changed prefix before the threshold continues full adaptation. The threshold is disabled at zero. Its candidate-to-candidate path total-variation bound is H p delta, below 1e-12 for the declared H=64 and p=1-exp(-1/64). This bound does not compare either candidate to the native law and does not bound changed-row log-score differences. The hard cutoff can break smoothness; the replay does not establish regular continuous-time filter admission.

The study uses the first 32 already saved native paths at each N=512 and N=1024, dimension K=2, arithmetic blocks of 16, and all 64 steps of length 1/64 from `artifacts/gaussian-joint-parent/20261002T161127396348Z`. The two new arms are a persistent Gaussian and an otherwise identical Gaussian reset to the activation conditional at every observed R_t. CPU float64 execution uses one path per batch and one numerical thread. No new native trajectory, learning update, random tape, or GPU workload is introduced. There is one declared run, with incremental path progress and failure retention.

Compare total joint negative log scores with the saved lifted baseline, particle filter64, and reset64 scores on exactly these same first 32 paths. The primary history contrast is persistent Gaussian minus reset Gaussian. Report source and configuration contributions separately, paired path means and standard errors, changed-assignment counts, source-update counts, shortcut counts, and observation-fiber residuals. Positive loss differences favor the second named arm. Passing numerical checks means finite scores and preserved conditional constraints; favorable prediction requires the actual score comparison. A descriptive difference on this one native realization is not an asymptotic RG or recursive-formation result.

The separate `regular-filter-error-route.md` bounds the exact integrated kernel Kq. Its bound is not automatically a certificate for sequential cubature with Gaussian projection. O1 still requires actual-law residual control and an admitted endogenous continuous-time realization; O4 remains separate.
