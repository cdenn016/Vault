# Source-adapted Gaussian parent study

October 2, 2026. The persistent Gaussian predictor has lower loss than its matched reset control on the declared saved paths: reductions of 5.4287 +/- 1.6054 and 10.8093 +/- 2.1081 nats per path at 512 and 1,024 agents, respectively. It also improves on the previous static-lift baseline. These are empirical paired standard errors over 32 paths at each size. The result supports useful history for this particular approximation and realization; O1 and O4 remain open.

## Construction and actual runtime

The [saved particle decomposition](joint-filter-loss-decomposition.md) attributes most of the predecessor loss deficit to source prediction. The [construction](source-adapted-filter-construction.md) uses shared positive spherical cubature to predict each source label, then Gaussian regression to carry its information to the next receiver. The full covariance update includes both conditional residual covariance and tilted local covariance. Each assignment-conditioned Euler sheet retains receiver and sender forces, followed by exact full-covariance Gaussian conditioning on the next block means.

The standalone profile experiments/gaussian_source_adapted.py passes RUN, THEORY and NUMERICS directly to run_source_adapted_study and gaussian_joint_scores. The active run_lab.py profile remains neighborhood. The declared inputs are the first 32 saved paths at each of N=512 and 1,024, K=2, block size 16, and all 64 steps of length 1/64. Activation, mobility, the global refresh rate, and the externally supplied structural schedule are reconstructed from the unchanged native metadata. Each receiver has the declared sources i+1 and i+17 modulo N, with independent GL+(2,R) comparison maps. The declared link scale is 0.2, temperature is 0.5, and global refresh rate is 1.0. Both arms score before observing the next retained configuration. The reset arm uses the same Gaussian algorithm but restarts from the activation conditional at every R_t.

The [contract](source-adapted-CONTRACT.md) declares the economical unchanged-assignment convention and the 1e-12 old-prefix shortcut before execution. Source probability includes hold and same-assignment refresh; an unchanged whole assignment uses the hold Gaussian for configuration prediction and conditioning. Changed assignments use the adapted Gaussian. Only an old-matching prefix with sufficiently small probability triggers the frozen-mean suffix. This defines normalized rows. The shortcut's path-TV bound below 1e-12 compares this candidate with its uncut counterpart, not with the native law; it does not bound changed-row log-score errors. Zero disables the cutoff. The full two-branch exact posterior is not implemented by this economical convention.

The dense stored covariance has (NK)^2 entries: approximately 8.4 MB per message at N=512 and 33.6 MB at N=1,024 before intermediates. Its number of parameters is independent of horizon, but it does not provide a smaller computational state than a fine configuration vector. All source assignments remain retained.

The [saved-score derivation](saved-score-upper-functional.md) evaluates the existing identity U(S)=D(P_RJ||S)+G, with candidate-independent nonnegative information gap G. Its path statistic is the saved native source log likelihood minus the candidate joint log density minus the known entropy of the projected native Gaussian innovation. It requires no native fine-state replay. For a fixed declared candidate its expectation is U; an individual statistic or sample mean need not bound the unknown KL. ## Continuous-time construction and remaining work

The [admission construction](continuous-gaussian-parent-admission.md) separately defines a frozen, autonomous continuous-time Gaussian-message parent with correlated observation/hidden noise, smooth uncut source jumps, positive covariance, nonexplosion and a deterministic retained-history decoder. It uses full covariance as does the replay, but no convergence from this scheduled finite-grid cutoff algorithm is asserted. The native no-change survival correction is explicitly omitted by that candidate. Membership in the regular-filter class is separate from prediction accuracy.

The [continuous error budget](continuous-parent-error-budget.md) treats that frozen candidate on its own stated assumptions. The [earlier discrete residual bound](regular-filter-error-route.md) instead applies to exact integration Kq and cannot simply be assigned to sequential cubature. Neither a finite replay nor candidate admission proves a useful epsilon-uniform error rate, endogenous structural feedback, or intrinsic recursive formation. Those remain the O1/O4 obligations.

The next budget measurement cannot be recovered from these saved scores. The native sampler creates full fine configurations, but joint_parent_experiment.py saves assignments, block projections and source scores before discarding its SwitchingHistory. The Gaussian scorer also keeps its message only transiently. A separately declared frozen-law runner must stream fine state and the continuous Gaussian message, evaluate sender-inclusive projected drift, and accumulate visible-jump likelihood and survival terms. The reusable seams are sheet_force, source_log_posterior and sequential_source_message with shortcut_mass=0. Replaying the current seeds would regenerate the scheduled discrete law; it would not create the frozen continuous candidate. Such a study has not been started.
