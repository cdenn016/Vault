# Complete saved-history comparison of binary source integration

The consistent binary probability-and-moment backend completed all 32 declared saved paths: sixteen each at N=512 and N=1024, both event-augmented meshes, horizon one and two original probes per path. Its fine-grid auxiliary total changed by -1.88235349 and -3.97757285 relative to retained cubature controls. The paired fine-grid total was lower on 32 of 32 paths. This is a descriptive result for one frozen learned model per size, not a measurement of retained-path KL or a general prediction-accuracy claim.

## Design and execution

The [predeclared contract](binary-source-history-CONTRACT.md) fixes GL+(2,R) links, cycle/stride-17 source support, block size sixteen, model seed 20261002, tau=0.5 and the archived learned mu, Sigma, pi and Theta. The new replay API takes mobility explicitly; this study uses the archived Sigma. Both grids use the original initial states, Brownian tape, Poisson events, source uniforms and probe draws. Coarse timestamps are looked up exactly within the fine mesh. The candidate carries its own mean and covariance after activation; no old cubature moments are injected into later updates.

All native states, assignments, timestamps, increments, probe labels/native scores and event counts matched the corresponding retained control exactly. The nominal maximum steps are 1/64 and 1/128. Across 32 paths there are 2,078 coarse intervals, 4,126 fine intervals and 30 saved proposals. The old cubature outputs were reused, not recalculated.

The single CPU invocation completed in 1378.157451 seconds with four workers and one numerical thread each, no retry and no GPU. Runtime used Python 3.12.7, NumPy 2.0.0, SciPy 1.16.0 and torch 2.10.0.dev20251210+cu128. The historical cubature elapsed time is not a matched performance benchmark. The recorded base revision is 1038dbd41efa2c968aea6ebe199da07cde030708; the executed replay additions were uncommitted at launch and are retained in the source snapshot.

## Mechanical validation and evidence

Three tiny replay tests passed in 1.991 seconds, covering exact same-backend recovery, preserved inputs and cross-backend native/probe parity. The initial three-test failure exposed an incorrect mobility assumption; passing mobility explicitly fixed the contract. Its JUnit remains alongside the final passing JUnit.

The independent NumPy reconstruction performed 1152 array comparisons over all 64 path/grid cases. It reconstructs receiver and sender forces, projected mobility, drift rates, native rows and sampled labels, mark/self/visible terms and every integral. Separate scalar pair-difference formulas checked all 216 summary means and standard errors. All 32 candidate archives are finite. Maximum retained-mean error was 1.80411242e-16; producer-reported covariance projection error was 1.51354623e-16; maximum log-row normalization error was 2.22044605e-16. Full covariance histories and self-prefix rows are not archived, so those update/projection checks remain producer evidence.

The [evidence folder](binary-source-history-evidence/) includes candidate arrays, per-path results, summary, metadata, JUnit, terminal output and executed source. Candidate NPZ files omit fields checked exactly equal to the [retained controls](continuous-square-root-evidence/). Overlay candidate fields on the matching control archive to reconstruct the complete replay output; the unchanged initial tape remains in the control.

## Scope and remaining work

This completes the declared saved-history backend comparison. It measures the accumulated effect of changing both row probabilities and their Gaussian moment updates. It does not isolate either change separately. Each selected nonlinear tilt is still approximated by a Gaussian for subsequent receivers, and native survival filtering is absent. The native conditional-information gap is unmeasured, so these finite-grid auxiliary totals are not retained-path KL. Practical O1 still requires native conditional accuracy and useful complexity/error control; both regular-filter horizon regimes and full O4 are not closed by this experiment. The active neighborhood profile, default source backend and historical Phase 13/14 evidence are unchanged.
