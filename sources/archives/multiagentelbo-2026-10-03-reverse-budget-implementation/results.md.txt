# Candidate-driven reverse-budget implementation checkpoint

The candidate-driven fine comparison and candidate-prefix source sampler are implemented. The final focused JUnit packets contain 33 distinct passing tests, with no failures, errors or skips. The N512/N1024 validation launcher, pre-run contract and large-network calculation remain pending. This is an implementation checkpoint for the existing [reverse-budget construction](binary-reverse-budget.md), not a measured path-accuracy result.

## Implemented path

`source_square_root.py` accepts optional supplied uniforms. It samples each receiver from the evolving candidate row before conditioning the next receiver, for both the cubature and binary-integral backends. Sampled calls return labels and their joint log probability; forced-label callers retain their previous output schema. Inputs are preserved, and full retention samples the native rows directly.

`reverse_budget.py` implements the minimum-Q drift correction with the same fine Brownian increment supplying the retained observation. It advances the Gaussian message by the existing forecast and endpoint-conditioning operations. Fresh candidate-driven coarse and fine trajectories share activation, proposal times, Brownian increments, proposal uniforms and independent probe draws. Each mesh may select different source labels. A proposal that reproduces the current complete assignment leaves the message unchanged. Probe rows estimate the full-mark reverse divergence using candidate prefixes, retaining the conservative self contribution.

The saved record contains states, means, assignment histories, Brownian increments, proposal rows and scores, probe rows and labels, costs, and final covariance. Step exceptions retain the current comparison/message state and random tape for diagnosis. The NumPy-only archive checker reconstructs finite-grid transition and cost arithmetic; it does not re-integrate every source probability or reconstruct the full covariance history.

## Validation and reachability

The [retained JUnit summary](reverse-budget-implementation-evidence/validation-summary.json) records 26 passing sampler and existing source-backend checks and seven passing comparison-kernel checks. The sampler checks enumerate candidate-prefix intervals, replay sampled labels through the forced-label route, check input preservation and reject invalid uniforms. Kernel checks cover an independent dense minimum-Q/shared-noise reference, local second-moment error, complete prefix enumeration, full retention, invisible and visible proposals, Brownian aggregation and saved-cost reconstruction. The small fixtures ground this implementation; they provide no large-network or formation result. Initial collection failures and expected missing-implementation failures are archived alongside the final packets.

The current `experiments/gaussian_continuous_square_root.py` profile remains on its native-driven experiment path. It does not dispatch this new sampler. The new entry point is `sample_reverse_budget(..., integration="binary_integral")`, which routes probes and proposal updates to `square_root_source_rows(..., uniforms=..., integration=...)`. The focused tests exercise that route directly. It requires CPU float64; the binary integration uses SciPy. CUDA was available when implementation began, but no GPU calculation is needed for this checkpoint.

The [NumPy archive smoke](reverse-budget-implementation-evidence/checker-smoke/independent-checks.json) passed on both grids of a saved N4 binary-integral path with one visible proposal per grid. Maximum reconstructed Euler discrepancy was 4.44e-16 and both final hidden-covariance Cholesky checks passed. This exercised the reconstruction function; the fixed N512/N1024 command-line profile remains unexecuted.

## Numerical limits and continuation

Endpoint Gaussian conditioning is a discretization of the shared-noise continuous filter. The tiny one-step second-moment check shows the expected quadratic local defect; it supplies neither a global error bound nor a continuous-time KL certificate for finite-grid outputs. Invisible proposal times still subdivide the numerical mesh. The exact-integral analytical construction and its finite-budget result do not certify this floating-point implementation or establish that the budget is small.

Next, write the one-shot N512/N1024 launcher and its pre-run contract, then execute one fresh paired-grid path per size with the NumPy reconstruction. The contemplated profile uses the saved learned activation, dimension 2, block size 16, horizon 1, 64 coarse intervals and two probes. These are pending numerical validation cases, not a full 32-path study or a retry of the previous failed native-path measurement. Quantitative O1 accuracy, forward native integrability, the preceding parity failure and O4 remain open. This implementation consumes no additional analytical round.
