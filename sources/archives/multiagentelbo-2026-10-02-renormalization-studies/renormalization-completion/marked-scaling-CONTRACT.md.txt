# Marked Gaussian diagonal study contract

## Scientific scope and model

This is a static quenched construction at one base point c_*. Cells have two R^2 agents, three parallel inverse-paired links I,A_i,B_i, and identity links between neighboring cell roots. Cell pairs (A_i,B_i) are identically distributed and independent across cells, with independent A/B draws. A_i=diag(1.4,0.7)+U_i and B_i=[[1,0.45],[0,1]]+V_i, with iid entrywise uniform noise in [-0.05,0.05]. This has proper bounded support inside GL+(2,R), includes nonisometries, and has noncommuting holonomy almost surely. Reverse copies are inverse maps, not independent draws.

The zero-mean quadratic action and dense Gaussian closure are those derived in obligations.md, with m^2=2, kappa=0.3, gamma=0.2, eta=0.4. The bound L=1.5 gives Lambda=5.5, q=1-2/5.5. The graph is an agent graph, not base geometry. Identity connecting-forest links and frozen coefficients are substantive restrictions.

Both belief and model sectors are independent identical copies with the same structural marks and identity cross-channel morphisms. All original forward and reverse copies survive blocking; stable array position is their persistent identity. Inherited internal tree edges become identity loops rather than disappearing. Model-law covariance closes in the full SPD family, not a fixed bandwidth/edge ansatz.

The raw measure M has Lebesgue density exp(-x^T H x/2+h^T x); the study uses h=0, while tests use nonzero h. The probability reference is rho=N(0,m^-2 I). The SAME map pushes M and rho at every stage. For retained mean mu, covariance C, reference covariance R, and raw log mass ell, the Lebesgue action constant is

c = (mu^T C^-1 mu + d log(2 pi) + log det C)/2 - ell.

Its Radon-Nikodym action relative to carried rho has quadratic precision C^-1-R^-1 and constant c_rho=c-[d log(2 pi)+log det R]/2. Mass/evidence is preserved. No depth resets rho to fresh Lebesgue or a fresh standard Gaussian. Under passive changes both model and reference covariances, marks, and covectors are carried. Tiny tests compare this pair and its constants.

## Boundary approximation and its deterministic bound

The exact theorem uses the infinite environment's transparent marginal. The executable study uses a finite padded principal precision with 64 cells on each side of the core. Its endpoint root diagonal includes 2 eta, so it is a Dirichlet principal restriction of the SAME infinite local operator, not a free endpoint action.

For Q=I-H/Lambda and Q_D its principal restriction, both operator norms are <=q. A power Q^p between core coordinates agrees with Q_D^p for p<2(padding+1): any walk leaving the padded domain and returning needs at least that many cell steps. The Neumann series therefore gives, for any normalized block matrix P supported on the core,

||P(C_infinity-C_padded)P^T|| <= (2/m^2) q^[2(padding+1)].

P has orthonormal rows in the declared canonical metric. This is an exact-arithmetic truncation bound; it is not a certified bound on floating-point error. The normalized sparse-solve residual is recorded separately. Comparing two independently padded restrictions has at most the sum of their theoretical boundary errors before rounding. The executable finite family is approximately, not exactly, projective.

## Profile and retained observables

The editable profile is experiments/gaussian_marked_scaling.py. RUN.seed is 20261002. THEORY.n_agents is [512,1024,2048,4096,8192]; all have two agents per cell and K=2. One environment of 4096+128 cells is generated once, corresponding to indices -64 through 4159. Each smaller size uses the same prefix and the same core origin. No environment is redrawn per N.

For n cells, ell=floor(log2(n)/2), B=2^ell. First retain z_i=(r_i+u_i)/sqrt(2), then normalized B-cell sums. This gives 16,32,32,64,64 core retained cells at the five sizes. The complete coarse covariance is at most 128 by 128 per channel, while the first three fixed coarse cells provide a 6-dimensional observable. Direct and staged retained laws, reference laws, offsets, and every structural copy are compared.

The susceptibility reference is a single empirical average over the largest core. To avoid an unproved infinite-constant-source solve, form f_i^(R) by a degree-R Neumann row-sum polynomial, R=63<padding. Each core row is exactly local to the saved environment before rounding. With q as above, the difference from the corresponding infinite row sum is at most

tail(R) = q^(R+1)/Lambda * [(2R+3)/(1-q) + 2q/(1-q)^2].

Symmetrization and averaging preserve this norm bound. This controls polynomial truncation only. The sample average is NOT the infinite-environment expectation chi; no arbitrary confidence interval or deterministic sampling-error bound is supplied. Diagonal covariance differences against this empirical reference are descriptive. Adjacent-block cross-covariance is compared with the explicit theorem bound q/[m^2(1-q)^2 B], plus the padding bound and the declared numerical tolerance.

## Execution and acceptance

The exact proposed command from the canonical checkout is:

    C:/anaconda/python.exe -B experiments/gaussian_marked_scaling.py

The profile sets MKL_THREADING_LAYER=SEQUENTIAL and all native thread counts to one before NumPy/SciPy imports, then enforces threadpool_limits(1). It uses CPU float64, sparse LU solves and local sparse matrix products. There is no torch import, GPU work, process pool, or full test suite.

Estimated peak core workspace at N=8192: 16896 microscopic scalar coordinates, 128 retained coordinates, and a dense solve RHS of roughly 17.4 MB. Two RHS/solution buffers and sparse factors should keep active numerical storage below 150 MB; native runtime baseline is additional. Five two-factor sparse cases and one 63-step two-column Neumann calculation should take seconds to at most a few minutes, not a training workload. This is a structural estimate, not an executed timing.

Tiny tests independently expand the action, check its uniform spectrum, compare direct/staged means and both covariances, compare effective precision/source/normalizer with a separately completed Schur integral, carry all marks under nonorthogonal frames, and ground padding/reference estimates against a larger finite inverse and a constant-environment Fourier-symbol susceptibility. These small models are validation only. The missing-module RED result is retained.

Large-study gates are sparse solve residual <1e-10, direct/staged errors <1e-10, every mark's direct/staged error <1e-10, positive retained covariance, and the explicit cross-block covariance bound. No monotone convergence or claimed universality is a numerical acceptance gate. The profile exits nonzero if any gate fails and retains the result. There is no automatic retry.

Each study writes one timestamped subdirectory under marked-scaling-evidence with environment.npz, per-size NPZ arrays (including all rooted marks for both channels), and summary.json. The latter records full profile, runtime/library/thread-pool information, timing, approximation bounds, descriptive results, and gate outcomes. The exact source files and their revisions should be retained by the parent with the final study record.

## Completion boundary

This study can validate implementation of compatible normalized blocking and a conditional massive diagonal theorem. It cannot establish autonomous parent dynamics, learned/switching structural histories, bounded structural interface size, non-Gaussian universality, or endogenous recursive formation. Those obligations remain separate.
