# Pointwise Gaussian network implementation: September 30, 2026

The first scale-ready Gaussian increment is implemented at c_*. One CPU study passed all 45 numerical comparisons across five 512-agent cases, following a ten-test tiny grounding packet. This is a conditional Gaussian implementation with held structural data. It does not establish switching-link closure, formation, an autonomous parent, or a thermodynamic limit.

## Implemented contract

The tensor layer is [network.py](../../../src/multiagent_elbo/realizations/gaussian/network.py). Its GaussianAction retains the complete real energy E(x)=x^T J x/2-h^T x+c. The offset c includes the proper node-prior and normalized record-likelihood constants, so log_mass reports the observed-record evidence as well as the normalized moments. The sign convention differs from the existing exact GaussianInfo oracle: that oracle's positive log coefficient is -c.

For each directed record, the residual is A_e x_receiver-B_e x_source-o_e, with SPD record precision Gamma_inv. The endpoint Gram blocks, information terms, and scalar terms are accumulated into the complete action. The maps can implement flat frame comparisons, independently supplied group maps, or distinct rectangular receiver/source comparisons. The law is Gaussian conditional on those maps, precisions, observed records, graph, and source assignments. Integrating random structural maps is a different operation and need not preserve Gaussianity.

Eliminating hidden coordinates retains the full Schur action, including generated cross blocks:
J_c=J_rr-J_rh J_hh^-1 J_hr,
h_c=h_r-J_rh J_hh^-1 h_h,
c_c=c+[log(det J_hh)-d_h log(2 pi)-h_h^T J_hh^-1 h_h]/2.
The parent also retains the reverse conditional gain -J_hh^-1 J_hr, intercept J_hh^-1 h_h, and precision J_hh. Its lift reconstructs fine moments from retained moments using that equilibrium reverse kernel, in the original coordinate order. It does not reconstruct an arbitrary nonequilibrium hidden conditional from retained moments alone.

Complex maps use the explicit realification R(L)=[[Re L,-Im L],[Im L,Re L]], with real coordinates followed by imaginary coordinates within each node. The complex examples use circular complex priors exp[-(z-mu)^* H(z-mu)], hence real precision 2 R(H). Their record likelihoods use the declared normalized real Gaussian convention. No latent Haar distribution is introduced.

This reuses the live theory's complete Gaussian action and Schur construction, rather than a new decimation theorem. Relevant source: Research/manuscripts/MultiAgentELBO_Theory/g07_coarse_maps.tex, complete-action and reverse-conditional construction around lines 567-650; the nonflat series-class and noncommuting examples retain their narrower established scopes. The source-first parent context is c11_network_coarsegraining.tex and the current PIFB2 modules. The repository's earlier fixed-fixture Gaussian realization and exact Fraction oracle remain unchanged.

## Dynamical boundary

GaussianParent exposes a separately declared stationary example: dX=-(J X-h)dt+sqrt(2)dW, with identity mobility, a held action, and stationary microscopic preparation. It computes the retained lag covariance selected from exp(-J t)J^-1, the memory kernel J_rh exp(-J_hh t)J_hr, and the positive conditional drift-variance tensor J_rh J_hh^-1 J_hr. The memory kernel needs hidden initial residuals and colored forcing to define a complete projected equation; the API does not provide a simulator from the kernel alone.

The tiny dynamics check compares lag covariance and memory with a SciPy oracle and distinguishes the projected process from an OU process chosen from the Schur marginal. The 512-agent study evaluates the drift-variance tensor only. Its nonzero values show that this coordinate projection has hidden coupling in the specified identity-mobility OU. No large-network path simulation, nonequilibrium activation, switching-link parent approximation, or gauge-covariant kinetic model was tested.
