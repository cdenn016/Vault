# Consistent binary source moments: implementation and saved-event results

The opt-in binary_integral backend now computes each two-label probability and its tilted Gaussian first and second moments from the same characteristic-function integral. It replaces the twelve-point integration primitive while retaining the sequential Gaussian approximation and the existing square-root residual-covariance update. This resolves the probability/moment consistency requirement identified by the [activation calibration](activation-source-calibration-RESULTS.md); it does not turn the joint posterior or survival filter into a Gaussian law.

## Reachable implementation

The [moment reference](../../../src/multiagent_elbo/realizations/gaussian/binary_source_reference.py) integrates probability, first moments and second moments together and constructs the complementary label from their exact sum identities. The [square-root source update](../../../src/multiagent_elbo/realizations/gaussian/source_square_root.py) accepts integration=binary_integral, restricted to CPU float64 with two labels. Selected physical moments are obtained through the incoming Cholesky factor. A numerical integration failure, non-interior probability or failed positive-definiteness check raises; there is no clipping, variance floor or retry.

For the budget runner, NUMERICS.source_backend=binary_integral is admitted by run_frozen_budget_study, copied into the worker context, passed by _sample_task to sample_frozen_budget, and routed through both source_budget_probe and _run_grid to square_root_source_rows. Sampled-prefix and self-assignment probabilities use the same backend as actual source updates. The default remains dense, and existing square_root profiles continue to use twelve-point cubature. The active run_lab.py profile remains neighborhood.

The [contract](binary-source-moments-CONTRACT.md) derives the Gaussian moment integrals, origin limits, complementary moments and componentwise tail bound. Adaptive numerical errors are estimates; after normalization by small label probabilities they are not certified moment-error bounds. Existing cubature-specific integrability and continuous-limit records have not been transferred to this new backend.

## Two actual saved source events

The [comparison runner](../../../experiments/compare_binary_source_moments.py) selected the first saved path with a visible source change at each size and its first change, before looking at scores or errors. It replayed saved fine-grid retained observations from activation, then ran both full receiver sequences on the same incoming Gaussian and observed assignment. No native trajectory, source draw or probe was generated. The complete calculation took 25.355500 seconds on one CPU thread.

The pre-event reconstructed candidate means and the old cubature post-event means matched the archives exactly in this execution. Both backends preserved the retained means and covariance null directions to below 5.2e-17, and every final hidden principal covariance passed Cholesky. Maximum reported moment-integration errors were below 1.25e-11.

The higher integral scores in these two cases are descriptive sensitivity results. They are not an out-of-sample accuracy estimate or a comparison against the exact native joint assignment law. Later rows depend on each backend's own Gaussian approximation to the selected prefix. The pre-event message is still the implemented candidate law, which omits survival filtering. No retained path KL, native filter accuracy, horizon-regime or general size claim follows.

## Validation and retained failures

Three final JUnit packets record 25 passing tests: 21 focused integral/default/consumer checks, one independent physical-lift check, and three spawned-runner backend cases. The tiny systems validate the formulas, complementary moment identities, coordinate rotations, physical moment mapping, retained fibers, positive hidden covariance, caller-state preservation, real update/probe routing and configuration propagation through a worker.

Two initial collection attempts each stopped with three import errors: existing test modules use bare imports of shared fixtures, while the tests package was not on sys.path. The successful command supplies -o "pythonpath=src tests". A broader runner check then exposed an existing bit-exact comparison between scaled and unscaled standard-error computations: all three backends differed by 3.47e-18 in the same assertion. The test now uses the independent two-sample identity SE=abs(x_1-x_0)/2 and a four-epsilon bound scaled to the input magnitude. Production statistics were not changed. The collection and roundoff failure XML files are retained, alongside the passing packets.

[Evidence](binary-source-moments-evidence/metadata.json) includes the saved-event metadata, row probabilities, labels, final means and covariance diagonals, executed sources, terminal output and all test packets. Full final covariance arrays are retained locally under artifacts/binary-source-moments/run and are not duplicated in Git. The source snapshot records the exact files used for the large-network comparison; the later runner-test correction does not change its numerical code.
