## 2. Independent reconstruction (written before reading the author's proof)

**Model facts.** On a matching sheet `M` the drift matrix `K_M = H_M + T(I + R_ev)` has rates `8+T` (twice), `4+5T` (twice), `5T` (twice), and `T` (six times), all at least `T`, so `e^{-K_M t}` is a contraction. With the orthonormal normals of `eq:rg-formation-cycle-normals`, `Z_M = span{(n+_e - n+_f)/sqrt2, n-_e, n-_f}` and `W_M = Z_M^perp` has dimension nine; both `H_M` and `R_ev` preserve the split, so the retained coordinate `y = P_W x` solves the autonomous equation `dy = -K_M y dt + sqrt(2T) P_W dW`. Writing `z_+ = ((n+_e + n+_f)/sqrt2).x` (retained, covector norm one) and `z_1, z_2, z_3` for the hidden coordinates, the partner costs are `D_e = (z_+ + z_1)^2 + z_2^2` and `D_f = (z_+ - z_1)^2 + z_3^2`. For an exterior edge `g`, the common residual `c_g = (r^b_g + r^m_g)/2` has covector norm `sqrt2`, annihilates `Z_M` (I checked the pairing with `n+_e - n+_f` vanishes and the pairing with `n+_e + n+_f` is `-1/sqrt2`), and `D_g >= c_g^2`. The center path is `e^{-K_M t} x_circ = e^{-Tt}(x_circ + p/4) - e^{-(8+T)t} p/4`, along which `r_int = -e^{-(8+T)t}`, `r_ext = c_g = e^{-Tt}(-3/2 + e^{-8t}/2)`, `z_+ = r_int`, and the hidden coordinates vanish.

**Conditioning.** The native `(X, S)` is a time-inhomogeneous Markov process because the rows `p(t)` are deterministic, and `E_theta` is `F_theta`-measurable. Hence the conditional law of the future given `E_theta` is the Markov evolution from `q^E_theta = Law(X_theta, S_theta | E_theta)` with the same deterministic rows, driven by the future Brownian increments, clock, and uniforms, which are independent of `F_theta` and keep their unconditional laws under `P(. | E_theta)`. On `E_theta`, `X_theta = e^{-K_M theta} X_0 + Z^M_theta` with `|X_0 - sigma x_circ| < rho` and `|Z^M_theta| <= delta_eps`, so `|X_theta - sigma e^{-K_M theta} x_circ| <= R_0 = rho + delta_eps`. For `t = theta + u` before the first departure, `Z^M_t = e^{-K_M u} Z^M_theta + Z'_u` with `Z'` built from the post-activation increments only, so the future tube radius is `R_0 + sup_{u<=h} |Z'_u|`, and the tube-failure probability is the unconditional one: Chebyshev with `E sup|Z'|^2 <= 384 T h` gives `384 T h / delta_eps^2 = 73728 eps^4 h`; the reflection principle per coordinate, requiring each of the twelve coordinates to stay below `(1/20)/sqrt12` and using `|Z'^k| <= 2 sqrt(2T) sup|B^k|`, gives `24 exp[-1/(76800 T h)]`, where `76800 = 1600 * 24 * 2`. Neither bound involves `P(E_theta)`, `c(m_0)`, or `m_0`.

**Coupling.** Realize the parent from the same initial retained state `C(X_theta, S_theta)`, the same Brownian motion, and the same clock. Between rings the retained coordinates coincide by pathwise uniqueness of the linear equation. At a ring where both self-propose, the native does not move and the parent returns to `P_W(y + F_M z) = y`. So the retained paths, assignment included, agree until the first ring at which either process leaves `M`. Therefore `TV <= P(tube exit) + P(native departs first, in tube) + P(parent departs first, in tube)`.

**Hazards.** A receiver with partner `j` and exterior source `k` chooses `k` with probability at most `(p_ik/p_ij) exp[-(D_ik - D_ij)/T]`. For the native, `D_ik >= c_k^2` and `D_ij` is the actual partner cost; a union over four receivers gives `4 Lambda e^{-g_nat/T}`. For the parent, `D_ik >= c_k(y)^2` is retained-measurable and the partner cost is `(z_+ + z_1)^2 + z_2^2` with thermal `z_1 ~ N(0, T/(8+T))`, `z_2 ~ N(0, T/(4+5T))`; the Gaussian identity gives `E exp[D_e/T] <= sqrt((8+T)/(6+T)) sqrt((4+5T)/(2+5T)) exp[(8+T) z_+^2/((6+T) T)] <= sqrt(8/3) exp[(4/3) z_+^2/T]`, hence `4 sqrt(8/3) Lambda e^{-g_par/T}`. The row ratio is at most `Lambda(t) = 2 e^{eps_L t} - 1` for the native rows (from `|p - 1/2| <= (1 - e^{-eps_L t})/2`) and for the parent rows (from `p^C_i(u) >= p_i(theta) e^{-eps_L u} >= e^{-eps_L(theta+u)}/2` and the same for `1 - p^C_i`). The compensator of the departure count up to the first departure, tube exit, or `h` bounds each departure-first probability by `h` times the hazard supremum, which gives the displayed `4(1 + sqrt(8/3)) Lambda(theta+h) h e^{-g/T}`.

**Gaps.** On the window, `T t <= 1/10` and `t >= theta >= 1/4`, so `|r_ext| >= e^{-1/10}(3/2 - e^{-2}/2) = 1.29603` and `|r_int| <= e^{-2} = 0.13534`. With the Chebyshev tube (`R = rho + 2 delta_eps = 0.0100144`) I obtain a parent gap `c^2 - (4/3) z_+^2 >= 1.6150` and native gaps between `1.6117` and `1.6208` depending on accounting; with the order-one tube (`R = rho + delta_eps + 1/20 = 0.0600072`) the parent gap is `1.4160` and the native gap lies between `1.3638` (each residual moved by `sqrt3 R`) and `1.4184` (orthonormal `z^+, z^-` decomposition). At `theta >= t_eps` the corresponding values are `1.795` to `1.804` and `1.560` to `1.614`. Every accounting gives `g > 1`, which is all the conclusion needs. The author's `1.60`, `1.39`, `1.80`, `1.61` sit inside or below these ranges, so before reading the proof the only open question was which accounting produced them.

**Mobility.** Since `eps_L <= 1` and `T(theta + h) <= 1/10`, `Lambda(theta+h) <= 2 e^{1/(10T)}` and `Lambda e^{-g/T} <= 2 e^{-(g - 0.1)/T} <= 2 e^{-9/(10T)}` for `g >= 1`. The rows cannot overcome the cost gap at any mobility in this range, so the coupling holds at `eps_L = eps` and no slow schedule is needed. The prefix failure `p_tilde = 73728 eps^4 t* + 4 Lambda(t*) t* e^{-1/T}` has first term at most `0.00753` (the function `eps^4 (2 log(1/eps) + 1)` increases on `(0, 1/100]`) and second term below `10^{-14}` because `8 e eps^{-2} t* e^{-eps^{-8}}` is astronomically small at `eps = 1/100` and smaller for smaller `eps`. For `eps_L <= eps`, `4 Lambda(t*) <= 4(2 e^{0.1022} - 1) = 4.86 < 5`, matching the source's `5`.

## 4. Defects

**D1 (minor, statement form; Section 2, part (c)).** The displayed bound `min{A_1, A_2} + 4(1 + sqrt(8/3)) Lambda h e^{-g_*/T}` with `g_* = 1.60` "for the first entry of the minimum" and `1.39` "for the second" is not a single well-formed inequality. Suggested fix: state it in that form, or state the weaker but unambiguous `TV <= min{A_1, A_2} + H(1.39)`, which follows because `H` decreases in `g`. Same fix in the abstract paragraph of the file, which uses `e^{-1/T}`; that version is also valid and is the cleanest.

**D2 (minor, illustration; Section 10, "Numbers at eps = 1/100").** "With `h = 1` the Chebyshev entry is `7.4e-4`" is true of that entry, but the theorem's bound at `h = 1` is the minimum, and the order-one entry there is `24 exp(-1.3e11)`, so the bound is astronomically small, not `7.4e-4`. The sentence should say that the order-one entry governs for every `h` up to about `1.3e10` and that the Chebyshev entry governs only when `h` is so small that `73728 eps^4 h < 24 exp[-1/(76800 T h)]`, which at `eps = 1/100` never happens for `h >= 1`. The task summary's "h = 1 gives 7.4e-4" inherits this. No bound changes.

**D3 (exposition; Lemma S4.7).** The partner-cost bound `D_e <= 2 zeta^2` loses a factor two in the `z_+^2` term. The exact decomposition `D_e = 2 (z^+_e)^2 + (z^-_e)^2` with orthonormal covectors gives `D_e <= (|r_int| + sqrt2 R)^2`, and the gaps become `1.416` (order one) and `1.615` (Chebyshev, limited by the parent). This is optional sharpening; the author's values are valid lower bounds.

**D4 (exposition, scope carried forward).** The prefix `E_theta` is the seeded sub-event of `prop:phil-seeded-contrast-formation`(b), the same event on which part (d) of the source activates. It is not the contrast-formation event or the first-block mark that `open:rg-formation-adaptive-family` conditions on. The author states this in Section 12; the parent record should not describe the theorem as activation on "the first-contrast event" without this qualifier.

**D5 (exposition; Section 13).** The scratch scripts cited by absolute path live in a session scratchpad and are not durable; only the condensed block in the file and the `stage4-evidence/` scripts are. The condensed block reproduces the gaps and the sheet-weight fits, but the constant arithmetic of Section 3 (`0.696`, `0.4369`, the slow-ball mass) and the quadrature check of the Gaussian identity are in the scratch script only.
