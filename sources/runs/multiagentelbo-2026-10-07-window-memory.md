## Setting and method

The calculation stays at one base point $c_*$ and uses the four saved N512/N2048, generator-prior widths .1/.3 cases. Its teacher is a finite whole-history source with fresh matter between episodes, thirteen slots $t=3,\ldots,15$, sixteen original source-label pairs and 192 candidate histories after excluding the complete truth chain. The cutoff is $t=3$; every initialized sequence assimilates the same twelve later original records. These are archived-input comparisons, not new network or history draws.

B16/B64 prior covariance-rank partitions are unchanged. The new $r=2,3$ contexts retain the current cell and up to $r-1$ preceding cells, starting at the actual cutoff cell without padding or future evidence. Both row arms share full correlated twelve-dimensional child/record pools and the same prior-only affine Gaussian parent channel from R8 to R2. Prior rows count candidate histories uniformly. The control instead uses each instance's actual cutoff-posterior history weights throughout the future row fit; it isolates a finite-source memory cost but is an instance-specific reference, not a deployable prior-only parent. Both arms assimilate all future records. Initialization uses the full archived teacher; afterward, runtime filtering has no teacher access.

The deployed codec retains rectangular sparse CSR transitions, correlated emissions, source routing and a message buffer charged at peak occupied context count. Its selected four-sibling output has a normalized observation-carrying composition square at two physical depths. This selected output is not a complete full-network boundary interface or independently autonomous children.
