# Extracting macroscopic dynamics: model problems and algorithms

> [!info] Citation
> Givon, D., Kupferman, R., Stuart, A. (2004). *Extracting macroscopic dynamics: model problems and algorithms*. Nonlinearity, 17(6), R55-R127. [DOI](https://doi.org/10.1088/0951-7715/17/6/R01)

No local copy: no open-access file passed validation on November 10, 2026. Reading basis: abstract.

## TL;DR

A review of how coarse-grained, macroscopic behavior of a time-evolving system can be determined from its microscopic description, covering model systems where this can be done explicitly and emerging algorithms for extracting effective lower-dimensional dynamics.

## Problem & setting

The abstract states that the primary aim of simulation is often prediction of macroscopic quantities. It describes four cases, since microscopic and macroscopic behavior can each be stochastic or deterministic, and it states that the model problems are useful for evaluating algorithms.

## Method

The review introduces mathematical tools for the model problems and uses specific instances to illustrate the algorithms. It describes its main purpose as unifying emerging ideas so that newcomers have structured access to the literature.
