## Relevance to this research

The manuscript cites this work for the channel filter of decentralized fusion, which subtracts the information shared along each link on tree networks, and treats it as the provenance device behind the cavity in belief propagation. It also cites it among the classical references for double counting of common information in track fusion. The manuscript's reading record only confirms the bibliographic details against Crossref, so none of this note rests on the paper's text.
