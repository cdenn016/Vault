# Reduced tensor network formulation for non-Abelian gauge theories in arbitrary dimensions

> [!info] Citation
> Yosprakob, Atis (2024). *Reduced tensor network formulation for non-Abelian gauge theories in arbitrary dimensions*. [Retained arXiv 2311.02541v3](https://arxiv.org/abs/2311.02541v3). [DOI](https://doi.org/10.1093/ptep/ptae091).

## Source result and scope

The reduced pure-gauge tensor formulation uses character expansion and generalized Clebsch-Gordan decompositions. Closed matrix-index structures around lattice sites can be contracted exactly, leaving representation and decomposition-sequence labels. The setting is a hypercubic Wilson-type gauge model.
