# Trajectory recognition as the basis for object individuation: A functional model of object file instantiation and object token encoding

> [!info] Citation
> Fields, C. (2011) Trajectory recognition as the basis for object individuation: A functional model of object file instantiation and object token encoding. Frontiers in Psychology: Perception Science 2: 49 [12 pp.] (doi: 10.3389/fpsyg.2011.00049).

Local PDF: [PDF](../pdfs/fields-2011-trajectory-recognition-as-the-basis-for-object-individuation-a-functional-model-of-object-file-insta.pdf)

## Summary

Fields proposes the specific trajectory recognition model of visual object individuation. Instead of treating an object file as an unexplained index attached to a current location, the model anchors it to a recognized trajectory. Dedicated networks downstream of motion detection are hypothesized to recognize a limited collection of simple and composite motion patterns, including coordinated but spatially disconnected displays such as point-light walkers. Current position and surface features are bound to this temporally extended representation.

The proposed hierarchy links perceptual persistence to available trajectory recognizers and their development through experience. Binding an object file to a category or a long-term object token is then hypothesized to suppress detailed trajectory information while retaining more general motion constraints. This provides an account of how immediate tracking and later recognition can use different information. The paper synthesizes existing anatomical, developmental, and behavioral findings and proposes further tests; it does not directly establish the posited network hierarchy. Its extensions to individual cognitive styles and developmental conditions remain conditional predictions.

## Relevance to this research

For [[Multi-agent variational free energy]], this illustrates why identity and memory may require temporally extended state rather than a current label alone. It also distinguishes information needed for tracking from information retained for later recognition. The proposal concerns neural visual mechanisms; it supplies neither a derivation of physical time nor a gauge-compatible rule for forming higher-level agents.
