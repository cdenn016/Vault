# The principle of persistence, Leibniz's law, and the computational task of object re-identification

> [!info] Citation
> Fields, C. (2013) The principle of persistence, Leibniz's law, and the computational task of object re-identification. Human Development 56: 147-166 (doi: 10.1159/000350206).

Local PDF: [PDF](../pdfs/fields-2013-the-principle-of-persistence-leibniz-s-law-and-the-computational-task-of-object-re-identification.pdf)

## Summary

Fields argues that an infant principle of object persistence redescribes a perceptual achievement without specifying its implementation. He distinguishes the observation that an infant responds as though an object persists from an explanation of how visual processing produces that response. The paper reviews the timing and development of motion processing, feature binding, categorization, and object files, emphasizing that a generic concept of a physical object does not by itself implement any of these operations.

Across longer gaps in observation, unchanged features are neither necessary nor sufficient for recognizing the same individual: objects change and distinct objects can look alike. Fields instead emphasizes learned constraints on possible motions, changes, and duplication, used to construct plausible histories linking encounters. These constraints support fallible heuristics. The article calls unrestricted re-identification computationally intractable, but its central argument concerns insufficient observational information rather than a formal asymptotic complexity reduction. Proposed modifications of infant experiments are intended to separate motion cues from assumed persistence; they are not new results reported in the paper.

## Relevance to this research

This supplies an implementation-oriented warning for [[Multi-agent variational free energy]]: declaring persistence or attaching the same identifier to successive records does not explain an observer's continuity inference. It supports separating an assumed state ontology from a mechanism that learns or maintains identity. It does not establish that statistical agents need human visual processing, nor derive the program's information-clock construction.
