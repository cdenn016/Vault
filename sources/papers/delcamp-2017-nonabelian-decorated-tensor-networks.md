# Towards a phase diagram for spin foams

> [!info] Citation
> Delcamp, Clement; Dittrich, Bianca (2017). *Towards a phase diagram for spin foams*. [Retained arXiv 1612.04506v1](https://arxiv.org/abs/1612.04506v1). [DOI](https://doi.org/10.1088/1361-6382/aa8f24).

## Source result and scope

The non-Abelian decorated-tensor algorithm uses rooted boundary graphs, Fourier gluing, and SVD with shared representation labels. Numerical examples use finite non-Abelian groups, including S3, on a cubic lattice.
