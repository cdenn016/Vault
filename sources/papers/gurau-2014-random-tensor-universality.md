# Universality for Random Tensors

> [!info] Citation
> Gurau, Razvan (2014). *Universality for Random Tensors*. [Retained arXiv 1111.0519v4](https://arxiv.org/abs/1111.0519v4). [DOI](https://doi.org/10.1214/13-AIHP567).

## Source result and scope

Gurau proves random-tensor universality for specified large tensor-index distributions. The invariant-distribution result requires the stated normalized cumulant structure and uniform bounds; the limiting covariance remains model dependent.

## Method and checked locators

Definitions 3–5, Eqs. (5)–(11), and Theorem 2, printed/PDF pp. 4–6. Published in Annales de l IHP Probabilites et statistiques 50(4), 1474–1525 (2014), DOI 10.1214/13-AIHP567.

[Retained PDF](../pdfs/gurau-2014-random-tensor-universality-arxiv-1111.0519v4.pdf). Locators refer to this exact version unless publisher pagination is explicitly named. Relevant method sections, rather than every section of the paper, were inspected.

## Relevance to this research

> [!note] Editorial: proposed transfer
> Use uniform cumulant and normalization requirements as a standard for any proposed large-network limit. Tensor index size is not agent count, and trace invariance is not local GL covariance or row-normalized attention. The theorem does not classify the present network universality class or prove meta-agent formation.
