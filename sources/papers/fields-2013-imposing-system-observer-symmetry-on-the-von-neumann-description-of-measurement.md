## Contribution and scope

Fields imposes symmetry between system and observer in the von Neumann measurement description and compares measurement with interpreting a physical device as executing an algorithm. Decompositional equivalence supplies the premise that changing the tensor-product description does not change the underlying physical dynamics. The proposed semantic map interprets global physical states as classical preparations, outcomes, and computational states. The resulting diagrams expose an implementation question: how does physical evolution realize a stable interpretation that can function as a record? The paper calls classical states virtual and suggests a relational answer. This is a structural and philosophical reformulation, not a dynamical solution that constructs classical records from a specified microscopic Hamiltonian or proves their stability and uniqueness.
