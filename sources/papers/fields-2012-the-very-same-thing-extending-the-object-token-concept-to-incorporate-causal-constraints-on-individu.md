# The very same thing: Extending the object token concept to incorporate causal constraints on individual identity

> [!info] Citation
> Fields, C. (2012) The very same thing: Extending the object token concept to incorporate causal constraints on individual identity. Advances in Cognitive Psychology 8: 234-247 (doi: 10.2478/v10053-008-0119-8).

Local PDF: [PDF](../pdfs/fields-2012-the-very-same-thing-extending-the-object-token-concept-to-incorporate-causal-constraints-on-individu.pdf)

## Summary

Fields extends the binding-of-items-and-contexts model of episodic recognition with fictive causal histories. An object token records an individual in a particular encounter; a singular category holds features used to recognize that individual. Feature agreement alone is insufficient when an object changes or resembles a different individual. The proposed extension requires a plausible history connecting a remembered token and context to the current encounter. Because the intervening events were not observed, this history is constructed rather than retrieved as a complete record.

The resulting BIC-FCH architecture links episodic tokens into an inferred history that supports prediction and updating. Fields hypothesizes that premotor planning supplies the transformations and that temporal-parietal interactions bind what, where, how, and why information. Updating singular categories and setting acceptable feature matches remain incompletely specified. The conclusion states that direct tests must control for attention and other confounds. Suggested connections to clinical conditions are hypotheses, not validated diagnostic mechanisms or treatment claims.

## Relevance to this research

This is a useful cognitive precedent for explicit records and stateful identity in [[Multi-agent variational free energy]]. It separates an observed event from an inferred connection between events, a distinction relevant to a normalized generative memory. Its proposed linked histories do not themselves provide a probability law, an exact sufficient statistic, or an autonomous parent-agent realization.
