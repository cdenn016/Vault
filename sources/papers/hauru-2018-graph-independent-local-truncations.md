# Renormalization of tensor networks using graph independent local truncations

> [!info] Citation
> Hauru, Markus; Delcamp, Clement; Mizera, Sebastian (2018). *Renormalization of tensor networks using graph independent local truncations*. [Retained arXiv 1709.07460v2](https://arxiv.org/abs/1709.07460v2). [DOI](https://doi.org/10.1103/PhysRevB.97.045111).

## Source result and scope

Graph-independent local truncation uses a bond environment to suppress directions with little effect on the surrounding contraction. The local operation does not prescribe a geometry change. The paper does not claim a generally optimal rank-minimizing choice; demonstrations include 2D Ising.

## Relevance to this research

> [!note] Editorial: proposed transfer
> Rank interfaces by their effect on declared exterior records, rather than raw local tensor magnitude. An efficient exact environment is not guaranteed on an arbitrary graph. Positivity, finite normalization, support-aware density error, and path-memory error need separate agent-law estimates.
