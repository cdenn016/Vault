# PIFB2 source modules

Compile PIFB2.tex from the parent manuscripts directory, for example with latexmk -pdf PIFB2.tex. The preamble, sections and appendices are separate editable modules. They share the parent references.bib. The figure is inline TikZ; no external image assets are required.

Each module names the parent file as its TeX root. Section numbers in the published document follow LaTeX, while the filename prefix records reading order (including transition and declaration modules).
