\chapter{Beyond the Fusion Construction}
\label{ch:outlook}

The constructions establish a language for agents that compare laws, receive internal records, and inherit descriptions across changes of scale. They also identify what a proposed hierarchy must preserve. A normalized predictor makes model agreement operational; an inherited update makes a retained description dynamical. These requirements are logically separate from identifying a coherent block at one instant.

The quantifiers in \cref{inh:recursive-formation} matter. A prescribed partition can admit exact dynamics without being selected by the dynamics. A block selected at one time can fail to persist. A parent can reproduce one record law and fail to reproduce the next response after an interaction. A smaller model-sector mobility can impose a timescale separation without explaining its origin. Each is a distinct intermediate construction, and each can be useful without resolving the formation problem.

\Cref{ch:fusion} supplies an exact two-stage example after a specific change of interaction: square-root KL costs produce a nonsmooth force and finite-time equality. The normalized local models, parent Fisher metrics, contact multiplicities, and fresh-response kernels are inherited. The initial class is restricted, and all agents eventually fuse into one component. This construction establishes a possible mechanism within the general statistical language. It does not establish the same mechanism for the smooth potential of \cref{ch:dynamics}.

The next unresolved case is a persistent collective with internally distinct belief or model parameters whose smaller parent state still determines future dynamics and responses. Candidate retained data must be tested by comparing fine states with identical parent data. The arithmetic-mixture counterexample shows that equal retained laws can conceal different derivatives even when the children have identical dynamical roles. Missing information may be a conditional dependence, an interface response, or memory of a shared source. It need not be a covariance, and it need not fit a predetermined distribution family. Observation-driven feedback must also be included explicitly before a result for fresh sampled records can be extended to an assimilating parent.

The same requirement constrains the eventual base geometry. An agent can support a curved connection when it has compatible directional transports. A state-dependent interaction between agents at one context does not determine those transports by itself. Deriving them requires a rule relating nearby contexts and its patch compatibility. A common geometry across agents requires a further compatibility statement. Neither task is made automatic by close model laws.
