The symbol $F$ for a discrete update and $F_i$ for curvature are used in separate constructions. A frame $U_i^a$ is an invertible map; the coding variable $U$ is a random representation. A Markov kernel returns a probability measure, whereas an ordinary map returns one value. Kernel composition is written in the order in which a law traverses the kernels.
