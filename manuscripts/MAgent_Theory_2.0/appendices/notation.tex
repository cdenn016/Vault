The symbol $F$ for a discrete update and $F_i$ for curvature are used in separate constructions, and the calligraphic $\mathcal F_i$ denotes a free energy. The letter $B$ denotes a connection representative $B_i$, block shape sums $B_I$ in the Wishart construction, the child-level probe class $B_I$ of the formation standard, and native rows $B^q_{IJ}$, each in its own construction; $A_I$ is likewise a shape sum in the Wishart construction and a protocol class in the standard, and $\mathcal C$ denotes a counterfactual class only inside the counterfactual clause. The symbol $\nu$ denotes a compared law $\nu_{ij}$ in the dynamics, a sector marginal $\nu_i^a$ in the interaction chapter, and a Wishart shape. A frame $U_i^a$ is an invertible map; the coding variable $U$ is a random representation. The letter $\Gamma$ denotes an interaction transition $\Gamma_{ij}$ and, in the causal-memory obstruction of the collective construction, the evolution map of a memory. A Markov kernel returns a probability measure, whereas an ordinary map returns one value. The symbol $\circ$ composes maps and juxtaposition composes kernels, in the order in which a law traverses them.
